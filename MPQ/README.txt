Place your legally owned Diablo II 1.10f MPQ files in this folder.

Required:
  d2data.mpq

Used when available:
  Patch_D2.mpq
  d2exp.mpq
  d2char.mpq
  d2sfx.mpq
  d2music.mpq

The game reads assets directly from these archives. It does not extract them.
Do not include these MPQ files when distributing the project.
